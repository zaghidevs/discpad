How it works

Paste an invite

Any public Discord invite works. Name the coin, pick a ticker and launch it on pump.fun. The server doesn’t need to sign up first.

Trades earn fees

Every buy and sell pays a creator fee. 90% of it is held for that server’s owner, across every coin launched for the server.

The owner claims

The owner signs in with Discord, we confirm they own the server, they add a Solana wallet and withdraw. Unclaimed fees wait for them.

Own a server?

If someone launched a coin for your server, the fees are already yours. Prove you own it and withdraw.

  1. Sign in with Discord. We only ask to see the servers you own.
  2. Pick your server from the list.
  3. Add a Solana wallet and claim everything it has earned.

Questions

Does the server owner have to agree first?

No. Anyone can launch a coin for any server with a public invite. The fees are held for the owner until they sign in and claim them.

How do you know who owns a server?

Claiming uses Discord sign-in. Discord tells us which servers your account owns, so only the real owner can claim a server’s fees.

Where do the fees come from?

pump.fun pays a creator fee on every trade. DISCPAD sends 90% of it to the server the coin was launched for and keeps 10% to run the platform.

What if the invite link expires?

Coins are tied to the server itself, not the link. A new invite to the same server still shows the same coins and balance.

What if ownership of the server changes?

Fees go to whoever owns the server when they claim.
