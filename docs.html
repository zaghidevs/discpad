How DISCPAD works

Launch a coin for any Discord server. Its creator fees are held for the server’s owner until they sign in and claim them.

Launching a coin

  1. Paste a Discord invite link for the server the coin should pay, like discord.gg/abc123. DISCPAD shows the server’s name, icon and member count so you can check it’s the right one.
  2. Give the coin a name, a ticker and an image.
  3. Press Launch coin and approve the transaction in your wallet. The coin is created on pump.fun and trades there like any other coin.

The server doesn’t need to know about DISCPAD first. Anyone can launch for any server with a public invite, including their own.

Where the fees go

pump.fun charges a small creator fee on every buy and sell. DISCPAD collects that fee for each coin and splits it:

90%
held for the owner of the server the coin was launched for
10%
kept by DISCPAD to run the platform

A server can have many coins launched for it. Its balance is the total across all of them, updated as trades happen.

Claiming as an owner

  1. Go to Claim fees and press Sign in with Discord.
  2. DISCPAD lists the servers your account owns, with each one’s balance.
  3. Pick a server and add a Solana wallet address.
  4. Press Claim. The balance is sent to that wallet, and the transaction link is shown so you can check it on Solscan.

Ownership check

Discord sign-in tells DISCPAD which servers your account owns. Only the account that owns a server can claim its fees. Moderators and admins can see the balance but can’t withdraw it.

DISCPAD only asks Discord for your username and the list of servers you’re in. It can’t read messages, post, or change anything in your server.

Invites and changes

  • Expired invite: coins are tied to the server, not the link. Any new invite to the same server shows the same coins and balance.
  • New owner: fees go to whoever owns the server at the moment they claim.
  • Never claimed: fees stay set aside for the server, with no deadline.

Rules

  • Coins can’t impersonate DISCPAD or Discord.
  • Coins with hateful or explicit names or images are hidden from the site.
  • Launching a coin for a server doesn’t mean the server endorses it. Coins show “launched for”, not “by”.

Risk

Coins launched through DISCPAD are memecoins. Their price can drop to zero. Fees depend on trading activity and aren’t guaranteed. Only use money you can afford to lose.
